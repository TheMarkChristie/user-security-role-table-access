You need the System Administrator role to use this. It reads the tables behind Dataverse security — users, roles, teams, privileges and column permissions — and in practice only an administrator can see all of them. Changing roles, profiles, teams or business units needs write access on top. Signed in as anything less, the parts it cannot read will say so rather than quietly showing you a wrong answer.

Secured columns this user can reach

A column marked as secured is hidden from everyone until a Column Security Profile grants it back — table-level Read is not enough. This lists every secured column in the environment and what this user's profiles, held directly or through a team, allow on each one.

These changes are real and there is no undo. Read the preview line by line, and start with one user before doing anything in bulk. Moving a business unit is the one to watch: Dataverse removes every security role the user has, and this tool re-applies the equivalents in the new unit straight afterwards — so if one of them has no counterpart there, the user comes out with less than they went in with. The preview tells you which, before you commit to it.
